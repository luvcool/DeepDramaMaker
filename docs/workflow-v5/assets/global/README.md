# Global Asset Library

작품과 독립적으로 재사용하는 공용 자산 저장소다. 배우의 본체(identity)와 목소리 본체를 프로젝트 배역 설정과 분리한다.

- `actors/ACTOR-*/actor.json`: 얼굴·체형·헤어 기준, 승인 참조 이미지 슬롯, 표현/포즈 기준
- `voices/VOICE-*/voice.json`: 음색·발화 특성, TTS/클론 참조 슬롯, 감정 샘플 슬롯
- `shared/`: 여러 작품에서 재사용 가능한 범용 차량·소품·배경. 작품 핵심 자산은 여기에 두지 않는다.

공용 자산에는 배역명·작품 내 직업·작품 의상·상처·스토리 상태를 기록하지 않는다. 그것들은 `works/{slug}/04_assets/`의 프로젝트 자산에 둔다.
