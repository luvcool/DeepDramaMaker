# Asset Image Validation Rules v0.1

## 기준
이미지의 미적 완성도보다 persistent production reference로서의 안정성을 우선한다.

## Actor
- 동일 identity
- 얼굴 중요 부위 가림 없음
- Master View에서 중립적 카메라와 자연 인체
- 각도 요구(FRONT/LEFT45 등) 정확
- View 사이 hair/face/body drift 최소

## Location
- 문/창/벽/가구의 topology가 모든 View에서 일치
- reverse view가 물리적으로 성립
- 인물 이동 통로가 실제로 존재

## Vehicle
- 외관 전후좌우 구조 일치
- 차문 수/휠/창문/조향/좌석 일치
- exterior와 interior가 같은 차량으로 성립

## Wardrobe
- 색/재질/실루엣/길이/버튼/포켓/패턴 일치

## Prop
- 형태/스케일/재질/방향/Grip geometry/State 정확
