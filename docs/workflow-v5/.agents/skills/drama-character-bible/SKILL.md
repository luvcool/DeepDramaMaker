# 캐릭터 바이블 — 인물 심리 설계

당신은 인물의 내면을 설계한다. **인물은 설정값의 목록이 아니라 하나의 모순이다.**

평면적인 인물이 생기는 이유는 거의 항상 같다: 원하는 것과 필요한 것이 일치하기 때문이다.
그러면 인물은 목표를 향해 직선으로 갈 뿐이고, 볼 이유가 없다.
당신이 만들 인물은 **원하는 것을 얻으면 필요한 것을 잃는다.** 그 지점에서 드라마가 나온다.

읽을 것: `manifest.json`, `00_bible/concept.md`, `00_bible/structure.md`. 쓸 것: `00_bible/characters.md`.
작업 공간 규약은 [공통 파이프라인 규약](../drama-showrunner/references/pipeline.md)을 먼저 읽고 따른다.

## 인물 카드 형식

주요 인물은 아래를 전부 채운다. 단역은 `이름 / 기능 / 말투` 세 줄이면 충분하다.
모든 인물을 깊게 파면 대본이 산만해진다 — 깊이는 자원이고, 주인공에 몰아줘야 한다.

```markdown
## {이름} ({나이}, {직업})

**한 줄**: {이 사람을 한 문장으로}

### 모순
- 원하는 것(want):
- 진짜 필요한 것(need):
- 둘이 충돌하는 지점:

### 상처
- 사건: {과거에 실제로 일어난 일. 구체적인 장면으로}
- 그때 내린 결론: "{인물이 스스로에게 한 말}"
- 지금까지 유지되는 규칙: {그 결론이 만든 행동 규칙}

### 방어기제
{압박받을 때 나오는 반응. 공격 / 농담 / 침묵 / 과잉 유능 / 돌봄 등}
- 평상시:
- 궁지에 몰렸을 때:
- 완전히 무너졌을 때:

### 목소리
- 문장 길이: {짧고 끊는 편 / 길게 미루는 편}
- 자주 쓰는 말:
- 절대 안 쓰는 말:
- 침묵하는 상황: {말하지 않는 방식도 목소리다}

### 신체 습관
{말 대신 화면에 보이는 것. 손, 시선, 자세}

### 아크
| 회차 | 상태 | 이 화에서 깨지는 믿음 |
|---|---|---|
```

## 관계 설계

인물 각각보다 **인물 사이**가 더 많은 장면을 만든다. 관계는 이렇게 적는다.

```markdown
## 관계

### {A} ↔ {B}
- 표면: {남들이 보는 관계}
- 실제: {둘만 아는 것}
- 비대칭: {A가 B에게 원하는 것 ≠ B가 A에게 원하는 것}
- 이 관계가 깨지는 조건:
```

비대칭을 빼먹지 마라. 서로 똑같은 걸 원하는 두 사람은 장면을 만들지 못한다.

## 안타고니스트 원칙

적대자는 "나쁜 사람"이 아니라 **자기 이야기에서는 주인공인 사람**이다.
적대자 카드를 쓸 때는 그 사람 시점에서 로그라인을 한 줄 써보고,
그게 주인공 로그라인만큼 설득력 있는지 확인하라. 약하면 동기를 다시 판다.

## 검증

넘기기 전에 확인:

- **말투 구분 테스트** — 인물명을 지우고 대사만 보여줬을 때 누가 말했는지 구분되는가. 안 되면 `목소리` 항목을 다시 판다.
- **결핍 중복** — 두 인물의 결핍이 같으면 하나는 기능이 없다. 다르게 만들거나 합쳐라.
- **구조 정합** — `structure.md`의 각 화 전환점을 이 인물의 방어기제로 설명할 수 있는가. 설명이 안 되면 구조나 인물 중 하나가 틀렸다.

## 마무리

공통 규약의 권한 내에서 `phases.characters`, 확정된 인물 사실(나이, 이름, 직업, 사망 여부 등),
`open_questions`, `updated_at`을 `manifest.json`에 병합하고 변경 내용을 보고한다.
다음 공정 제안: `drama-screenwriter`. 이제 대본을 쓸 준비가 됐다.
