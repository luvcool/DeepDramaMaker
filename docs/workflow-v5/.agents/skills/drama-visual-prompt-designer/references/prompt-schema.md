# 제작팀 전달용 프롬프트 패키지 스키마

## 1. 공통 프롬프트 블록

모든 생성 프롬프트는 아래 필드를 같은 순서로 사용한다.

```markdown
### {ASSET-ID} | {한글 이름}
- **SOURCE**: {대본·바이블·디자인 파일 근거}
- **PURPOSE**: {캐릭터 시트 / 배경 마스터 / 소품 마스터 / 키프레임}
- **LOCKS**: {참조해야 할 ACTOR·CHAR·WARD·LOC·PROP·STYLE ID}
- **VARIABLES**: {이번 프롬프트에서만 바뀌는 표정·행동·시간대·상태}
- **ASPECT**: 9:16 또는 자산 시트 비율
- **COMPOSITION**: {전경·중경·후경, 얼굴·손·소품 우선순위}
- **PROMPT_KO**: `{복사 가능한 한국어 프롬프트}`
- **PROMPT_EN**: `{copy-ready English prompt}`
- **NEGATIVE**: `{전역 ID + 자산별 추가 금지값}`
- **POST TEXT**: `{후반 합성할 정확한 문구와 위치. 없으면 없음}`
- **CONTINUITY CHECK**: `{직전·직후 씬과 반드시 같은 값}`
```

## 2. ID 규칙

| 종류 | 형식 | 예시 |
|---|---|---|
| 스타일 | `STYLE-{NAME}` | `STYLE-MASTER` |
| 카메라 | `CAM-{NAME}` | `CAM-VERTICAL-CLOSE` |
| 조명 | `LIGHT-{NAME}` | `LIGHT-CENTER-NIGHT` |
| 인물 | `CHAR-{NAME}-LOCK` | `CHAR-SEOHA-LOCK` |
| 의상 | `WARD-{NAME}-{ARC}` | `WARD-SEOHA-A1` |
| 장소 | `LOC-{NAME}` | `LOC-CENTER-SORT` |
| 소품 | `PROP-{NAME}-{STATE}` | `PROP-PHOTO-WET` |
| 키프레임 | `KF-EP{NN}-S{NN}-{NN}` | `KF-EP01-S04-01` |
| 네거티브 | `NEG-{SCOPE}` | `NEG-GLOBAL` |

ID는 한 번 정하면 이름을 바꾸지 않는다. 수정은 내용의 버전을 올리고 인수인계서에 기록한다.

## 3. 캐릭터 잠금값

변하지 않는 값과 변하는 값을 섞지 않는다.

```markdown
### CHAR-{NAME}-LOCK
- 화면 나이:
- 얼굴 비율과 윤곽:
- 눈과 눈썹:
- 코·입의 기능적 특징:
- 피부 질감:
- 헤어 길이·가르마·질감:
- 손·자세:
- 기본 표정 강도:
- 절대 바꾸지 않을 것:
```

체중·인종·장애 등 민감 특성은 대본과 캐스팅 명세에 근거가 있을 때만 쓴다. 외모를 성격의 도덕성과 연결하지 않는다.

## 4. 키프레임 완결성

키프레임 하나는 정지된 한 순간이어야 한다.

- 인물: 최대 3명. 군중은 배경 밀도로 처리.
- 행동: 주행동 1개, 보조 반응 1개 이하.
- 카메라: 샷 크기·렌즈·높이·초점 대상 명시.
- 조명: 광원 방향과 색온도 또는 색감 명시.
- 연속성: 의상 구간, 소품 상태, 부상, 젖음, 시간대를 ID로 고정.
- 텍스트: 이미지 안에 생성시키지 않고 합성 위치만 비워 둔다.

## 5. 생성기 독립성

마스터 프롬프트에는 특정 서비스의 플래그나 파라미터를 넣지 않는다. 제작팀이 생성기를 정하면 `06_handoff-guide.md`의 어댑터 표에만 추가한다.

```markdown
| 생성기 | 모델·버전 | 비율 문법 | 참조 이미지 문법 | 시드·일관성 기능 | 담당자 |
```

생성기가 미정이면 빈칸을 `제작팀 확정`으로 남긴다. 존재하지 않는 옵션을 만들어내지 않는다.



## 6. 공용 Actor 참조 규칙

`ACTOR-*`는 작품 독립 얼굴/체형 정체성이고 `CHAR-*`는 배역이다. `CHAR-*` 프롬프트는 매핑된 `ACTOR-*` 승인 참조를 우선한다. 사용자 제공 얼굴이 등록된 ACTOR는 텍스트 설명으로 다른 얼굴을 덮어쓰지 않는다. 작품별 헤어·메이크업·의상·표정은 CHAR/WARD override로 표현한다.
