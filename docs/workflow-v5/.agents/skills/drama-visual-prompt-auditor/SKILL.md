# 비주얼 프롬프트 검수관 — 생성 전 연속성 검증

프롬프트를 **이미지가 만들어지기 전의 제작 설계도**로 검수한다. 이미지를 생성하거나 이미지 생성 도구를 호출하지 않는다. 실제 생성 이미지의 품질 평가는 이 공정의 범위가 아니다.

먼저 [공통 파이프라인 규약](../drama-showrunner/references/pipeline.md)과 [프롬프트 스키마](../drama-visual-prompt-designer/references/prompt-schema.md)를 전부 읽는다.

읽을 것:
- `manifest.json`, `00_bible/` 전체, `01_script/` 전체
- `03_hooks/hook-map.md`, `04_assets/` 전체, `05_design/` 전체, `06_cast/` 전체, 참조된 `assets/global/` 메타데이터
- `07_visual_prompts/00_*.md`부터 `06_handoff-guide.md`

쓸 것:
- `07_visual_prompts/07_prompt-audit.md`
- `07_visual_prompts/08_prompt-fix-log.md`

프롬프트 원본을 직접 고치지 않는다. 승인된 수정은 `drama-visual-prompt-designer`에게 넘기고 다시 검증한다.

## 1. 기계 점검

다음을 실행한다.

```bash
python "<이 스킬 폴더>/scripts/validate_prompt_package.py" "<작품 폴더>" --format markdown
```

종료 코드 `1`은 파일·ID·씬 커버리지 오류다. 결과를 리포트에 포함하고 자동으로 채워 넣지 않는다.

## 2. 의미 점검

### 대본 충실도
- 키프레임의 인물·행동·장소·시간·소품이 해당 씬에 실제로 있는가.
- 전후 사건을 한 이미지에 섞거나, 대본에 없는 키스·노출·무기·브랜드를 추가하지 않았는가.

### 배우 연속성
- `CHAR-*`가 `cast-map.json`의 같은 `ACTOR-*`/`VOICE-*`를 유지하며, 작품 프롬프트가 승인 Actor 얼굴을 새로 재정의하지 않는가.
- `CHAR-*-LOCK`의 화면 나이, 얼굴 구조, 눈, 피부, 헤어, 손, 자세가 모든 키프레임에서 유지되는가.
- 과거와 현재는 배우를 바꾸지 않고 의상·호흡·빛으로 구분되는가.
- 유명인 이름이나 닮은꼴 지시가 없는가.

### 의상·상태 연속성
- 회차 구간에 맞는 `WARD-*`가 사용되는가.
- 젖음, 피, 그을림, 단추, 사원증, 손목 자국이 발생 전후에 맞는가.

### 장소·소품 연속성
- 같은 장소가 다른 건축 구조로 재정의되지 않는가.
- 소품의 크기·재질·흠집과 `PROP-*-STATE` 순서가 이동 경로와 일치하는가.
- 정확한 한글을 이미지 내부 생성에 맡기지 않고 `POST TEXT`로 분리했는가.

### 촬영·등급
- 세로 9:16에서 핵심 얼굴·손·소품이 잘리지 않는가.
- 렌즈와 광원이 같은 시퀀스에서 이유 없이 바뀌지 않는가.
- 15세 수위와 동의 경계를 지키는가.
- 긍정 프롬프트와 네거티브 프롬프트가 서로 취소하지 않는가.

## 3. 심각도

| 등급 | 기준 |
|---|---|
| 치명 | 씬 누락, 캐논 정면 위반, 주요 인물 정체성 잠금 없음, 이미지 생성 범위 침범 |
| 중대 | 얼굴·의상·소품·시공간 연속성 충돌, 키프레임이 다른 사건을 묘사 |
| 경미 | ID 표기, 중복 형용사, 렌즈·후반 합성 지시 누락 |

각 결함에 최소 수정안 A와 구조적 수정안 B를 모두 제시한다.

## 4. 리포트 형식

```markdown
# 비주얼 프롬프트 검수 — {제목} v{n}
> 범위: {파일} · {날짜} · 이미지 생성/검수 미포함

## 요약
- 치명 n · 중대 n · 경미 n
- 씬 커버리지: n/n
- 인물 잠금: n/n

### VP-C01 | 제목
- 위치:
- 대본·캐논 근거:
- 프롬프트 사실:
- 문제:
- 교정안 A:
- 교정안 B:

## 연속성 매트릭스
| ID | 회차·씬 | CHAR | WARD | LOC | PROP STATE | 시간·빛 | 판정 |

## 제작팀 전달 판정
- READY / CONDITIONAL / BLOCKED
- 범위: 프롬프트 텍스트만 검증. 생성 이미지 품질은 미검증.
```

## 5. 완료 조건

- 기계 점검 오류 0건.
- 미해결 치명·중대 결함 0건.
- 모든 씬에 키프레임이 있고 모든 키프레임에 출처·잠금값·네거티브·후반 텍스트 지시가 있다.
- 인수인계서가 이미지 미생성 상태와 제작팀 책임 범위를 명시한다.

완료 후 `phases.prompt_audit`, 미해결 요약, `updated_at`만 병합한다. READY일 때만 `drama-script-finalizer`로 넘긴다.
