# 소품 명세 — 《없던 사이》

## 극적 소품

### P-01 | 젖은 커플 사진
- **정체**: 코팅 가장자리가 물에 불은 4×6 사진. 처음에는 얼굴 부위만 빛에 타 보이지 않는다.
- **출처**: 서하와 도윤의 과거 촬영물. 관계 삭제 후 호텔 잔시에 공명 증거로 남음.
- **이동 경로**: ep01 발견·비현실 격리 캡슐 봉인 → ep19 잔시 아카이브 공명 → ep21 도윤이 최초 현실 물질화·반출 → ep23 봉인 상자 → ep24 소각.
- **의미 변화**: 연인 증거 → 현재 기억의 대가 → 과거를 놓는 마지막 물건.
- **연속성 주의**: ep01–20에는 캡슐 밖 현실 물건으로 묘사하지 않는다. ep21 이후 `반출 봉인` 표찰. 젖은 모서리는 마르지만 펴지지 않는다.

### P-02 | 100일 손목시계
- **정체**: 얇은 검정 가죽줄, 작은 사각 문자판. 뒷면 `D에게, 100일은 안 버리기`.
- **출처**: 과거 서하가 도윤에게 준 100일 선물.
- **이동 경로**: ep07 모텔 잔시 발견 → ep08 과거 재생 후 잔시 보관 → ep19 아카이브 공명 → ep23–24 소각.
- **의미 변화**: 소유 증명 → 몸의 습관 → 지킬 수 없었던 약속 → 새 약속을 위해 버리는 증거.
- **연속성 주의**: 현실 도윤에게 물리 시계는 없고 손목 자국과 용두 누르는 동작만 남는다.

### P-03 | 도윤의 셔츠와 단추
- **정체**: 여러 번 빨아 목깃이 부드러운 회청색 셔츠, 두 번째 단추 없음, 안쪽 `D`.
- **출처**: 과거 도윤이 서하 집에 두었고 관계 삭제 당시 서하 사물함에 현실 물건으로 남음.
- **이동 경로**: ep08 사물함 노출 → ep09 도윤 착용·영수증 발견 → 아카이브 봉인 → ep23–24 소각.
- **의미 변화**: 설명 없는 친밀감 → 현재의 질투와 동의 경계 → 삭제로도 지워지지 않은 생활 → 포기.
- **연속성 주의**: 사물함 발견 때 석 달 전 센터 세탁표가 반드시 보인다.

### P-04 | 영수증 묶음
- **정체**: 열전사 글씨가 흐려진 법인카드 영수증. 장소와 시간만 간신히 읽힌다.
- **이동 경로**: ep09 셔츠 주머니 한 장 → ep10 박태식의 종이 묶음 → 문서번호 발견 → ep23 소각.
- **의미 변화**: 소비 기록 → 데이트 동선 → 전관 폐기의 입구.

### P-05 | 숨은 음성 트랙
- **정체**: 유리 실린더 안에서 자주색 파형으로 보이는 28초 음성.
- **이동 경로**: ep05 잔시 발견 → ep06 현실 반출·재생 → 센터 보관 → ep23 소각.
- **의미 변화**: 고백의 잔향 → 과거 도윤의 경고 → 현재 도윤에게 선택권을 돌려주는 유언.

### P-06 | 전관계 폐기 동의서
- **정체**: 전산에서 삭제되고 압인 자국이 남은 종이 원본. 두 서명은 같은 필압으로 보이되 필체는 확실히 다르다.
- **이동 경로**: ep11 종이 창고 발견 → ep12 마지막 장 공개 → ep17–18 과거 서명 재현 → 기록 보존.
- **의미 변화**: 배신 증거처럼 등장 → 공동 희생의 증거 → 현재 선택을 대신할 수 없는 과거 문서.
- **연속성 주의**: 원본은 반출하지 않고 창고 안에서만 본다.

### P-07 | 43명 모니터·명단
- **정체**: 이름만 적힌 종이 명단과 43개의 세로 얼굴 모니터.
- **이동 경로**: ep12 공개 → ep13 현실 확인 → ep17 사고 재현 → ep24 균열 소멸.
- **의미 변화**: 추상적 숫자 → 수진과 아이의 삶 → 주인공 선택의 실제 비용.

### P-08 | 업무용 단말기
- **정체**: 모서리가 깨진 공공기관형 검정 단말기. 버튼은 `폐기`와 `취소`가 같은 크기.
- **이동 경로**: 전편 수거 업무 → ep24 키스 직후 폐기 의향 감지 → 취소.
- **의미 변화**: 남의 후회를 처리하는 도구 → 자기 방어기제를 알아차리고 거부하는 선택 장치.

### P-09 | 사원증
- **정체**: 검정 메탈 클립과 양면 케이스.
- **이동 경로**: 서하·도윤 상시 착용, 현숙 ep11 사진 면 은폐, ep24 정면 전환.
- **의미 변화**: 이름을 대신하는 표식 → 기억 손실 때 타인을 식별하는 차가운 증거 → 얼굴을 인정하는 행위.

### P-10 | 잔시 격리 캡슐
- **정체**: 손바닥 두 개 너비의 투명 밀폐 용기. 잠금이 닫히면 안쪽 물건 가장자리가 자주색으로 굴절된다.
- **이동 경로**: ep01 사진 비현실 봉인 → 센터 아카이브 보관 → ep21 반출 잠금 해제.
- **의미 변화**: 진실을 보되 현실에 소유하지 않는 안전거리 → 대가를 감수하고 물질화하는 경계.
- **연속성 주의**: 잠금 전·후 UI 문자는 비워 두고 후반 합성한다.

### P-11 | 검은 태그·탐침
- **정체**: 모서리가 닳은 무광 검정 태그와 짧은 금속 탐침. 활성 시 숫자 대신 얇은 자주색 테두리만 생성한다.
- **이동 경로**: 전편 잔시 진입·원인 물품 추적·출구 고정.
- **연속성 주의**: 실제 시간 숫자와 장소 코드는 이미지 생성에서 비우고 POST TEXT로 합성한다.

### P-12 | 유리 음성 실린더
- **정체**: 손가락 길이의 투명 실린더, 내부에 자주색 파형이 떠 있다.
- **이동 경로**: ep05 응축 → ep06 현실 반출·재생 → ep23 소각.
- **연속성 주의**: 깨지지 않으며, 반출 뒤 표면에 얇은 흰 봉인띠가 생긴다.

### P-13 | 수진의 열쇠고리
- **정체**: 표면 도색이 절반 벗겨진 작은 금속 열쇠고리.
- **이동 경로**: ep13 아이 → 도윤 → ep14 수진의 증거 봉투 → 센터 보관.
- **의미 변화**: 생명의 은인 증표 → 찾지 않기로 한 기억의 선택.

### P-14 | 집 열쇠와 `02:17` 쪽지
- **정체**: 평범한 은색 집 열쇠와 네 번 접힌 메모지.
- **이동 경로**: ep15 옥상 잔시 → ep16 집 잔시 식탁 아래 → 빛에 소실.
- **연속성 주의**: 쪽지 문자는 생성하지 않고 손글씨 영역만 확보한 뒤 후반 합성한다.

### P-15 | 분리선·부러진 서명 펜
- **정체**: ep09–10 노란 안전선, ep19–20 빨간 작업선, ep20–21 손 안에서 부러진 검정 전자펜.
- **의미 변화**: 행정적 거리 → 자발적으로 허용한 한 칸 → 반복 폐기 거부.
- **연속성 주의**: 노란 선과 빨간 선을 같은 회차에 혼용하지 않는다. 부러진 펜촉은 ep21 S#1까지 두 조각 그대로다.

### P-16 | 유리벽 메모와 이송표
- **정체**: 굵은 검정 펜으로 쓴 흰 메모지, 동관 청색·서관 적갈색 이송표.
- **이동 경로**: ep19 격리 복도와 이송 엘리베이터.
- **연속성 주의**: 메모 문자는 POST TEXT 처리, 손글씨 방향과 종이 순서만 이미지에서 고정한다.

### P-17 | 현재형 커피 컵 두 개
- **정체**: 서로 다른 흠집과 유약 흐름을 가진 작은 도자기 컵.
- **이동 경로**: ep24 카페 테이블 한정.
- **의미 변화**: 과거 유품 없이 처음 생기는 두 사람의 공동 물건.
- **연속성 주의**: 서하 컵은 손잡이 오른쪽, 도윤 컵은 왼쪽. 컵을 기념품처럼 이후 자산으로 확장하지 않는다.

## 배경 소품
- 분류실: 검은 태그, 라벨 프린터, 세척 브러시, 봉인 테이프, 라벤더 선택지가 있는 자판기.
- 기록창고: 붉은 면사, 수기 장부, 방습제, 안경천, 날짜 도장.
- 사고실: 손바닥 인식판, 이중 펜, 43개 균열 아이콘, 냉각 호스.
- 소각실: 투명 운반 상자, 공동 버튼, 백색광 차광면, 종이 체크리스트.

## 신규 설정 여부
- 이야기 기능을 바꾸는 신규 물건·공간은 추가하지 않았다.
- 화면 구현을 위해 단말기의 두 버튼 크기, 세탁표, 소각 백색광 같은 외형만 구체화했다.
