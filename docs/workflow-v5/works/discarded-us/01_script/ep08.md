# 없던 사이 8화 — 백일째 첫 만남
> 버전 v2 · 씬 7개 · 예상 5분

## S#1. 100일의 버려진 시간·포장마차 / 내부 / 밤

좁은 포장마차. 김 오른 비닐막 너머 현재의 서하와 도윤이 앉아 있다. 같은 테이블 과거 쪽에서 서하가 시계 상자를 내민다.

**과거 서하**
백 일 동안 안 버린 물건, 처음이죠?

**과거 도윤**
사람까지 포함하면 두 번째.

**과거 서하**
첫 번째는 누군데요.

**과거 도윤**
지금 질투하는 사람.

과거 서하는 상자를 다시 빼앗으려 한다. 과거 도윤이 상자 끝만 잡는다.

**과거 도윤**
농담 취소. 첫 번째도 당신.

현재 서하가 자기도 모르게 웃는다.

**도윤**
말투가 지금보다 더 별로네요.

**서하**
웃은 건 저 사람입니다.

**도윤**
현재 입꼬리도 공범인데요.

## S#2. 포장마차 테이블 반대편 / 내부 / 연속

과거 도윤이 상자를 열지 못하고 만지작거린다.

**과거 서하**
마음에 안 들면 바꿔요.

**과거 도윤**
받기도 전에 출구부터 줍니까?

**과거 서하**
선택권입니다.

**과거 도윤**
떠날 선택권 말고 남을 선택권은요?

과거 서하가 소주잔 각도를 바로잡는다. 대답하지 않는다.

현재 서하도 앞의 빈 잔을 똑같이 바로 세운다. 현재 도윤이 두 손을 비교한다.

**도윤**
습관은 증거 아닙니까?

**서하**
법적 효력 없습니다.

**도윤**
개인적으로는요?

**서하**
심문 중입니다.

**도윤**
과거의 선배님을요, 지금의 선배님을요?

서하는 대답 대신 과거의 자신을 본다.

## S#3. 포장마차 뒤편 / 외부 / 버려진 밤

과거의 두 사람이 빗소리 아래 선다. 과거 도윤은 시계를 차지 못한 채 상자만 쥔다.

**과거 도윤**
내가 또 가볍게 굴면 버려도 돼요.

**과거 서하**
그럼 나도 같이 버려져요.

**과거 도윤**
사람은 안 버립니다.

**과거 서하**
당신은 농담 속에 진짜를 자꾸 숨겨요.

**과거 도윤**
진짜로 말하면 무거워서 도망갈까 봐.

**과거 서하**
내가 도망갈지 당신이 왜 정해요?

과거 도윤의 웃음이 사라진다.

**과거 도윤**
그럼 묻겠습니다. 남아도 됩니까?

과거 서하가 대답 대신 그의 손목을 잡는다.

현재 도윤이 현재 서하를 본다.

**도윤**
저때도 선배님이 먼저네요.

**서하**
기억 없는 사람끼리 승부 내지 맙시다.

## S#4. 포장마차 차양 아래 / 외부 / 연속

과거 서하가 도윤의 손목에 시계를 채운다. 잠금쇠가 잘 걸리지 않는다. 두 사람 손이 빗물에 미끄러진다.

**과거 서하**
당신이 나 안 버리면, 나도 안 버려요.

**과거 도윤**
조건부 계약입니까?

**과거 서하**
쌍방 동의입니다.

**과거 도윤**
기간은요?

**과거 서하**
다음 백 일까지.

**과거 도윤**
갱신은 자동으로.

과거 서하가 잠금쇠를 닫는다. 현재 도윤 손목의 시계도 동시에 잠긴다.

현재 서하가 급히 풀려 하지만 잠금쇠가 움직이지 않는다.

**서하**
잔시가 물건을 고정했습니다.

**도윤**
과거의 계약이 아직 유효한가 봅니다.

**서하**
현재 당사자 동의가 없습니다.

## S#5. 포장마차 / 내부 / 잔시 붕괴 전

반출 경고가 뜬다. `장착 상태로 이탈 시 현실 반출`. 서하가 도윤 손목을 자기 쪽으로 끌어당긴다.

**서하**
빼요. 대가 생깁니다.

**도윤**
이건 원래 제 손목에 있던 물건입니다.

**서하**
그래도 과거가 현재로 넘어오면 규칙은 같습니다.

도윤이 가까이 와 손목을 내민다. 맥박이 서하 손끝 아래 뛴다.

**도윤**
그럼 빼주세요.

**서하**
당신도 할 수 있잖아요.

**도윤**
선배님이 채운 걸로 보이니까요.

**서하**
과거의 내가요.

**도윤**
지금의 선배님이 풀면 공평하죠.

서하가 잠금쇠를 푼다. 이미 열렸는데 손끝이 맥박 위에서 떨어지지 않는다.

    [10초. 도윤은 손을 당기지 않고 서하가 놓을 때까지 기다린다.]

## S#6. 포장마차 출구 / 내부 / 붕괴

시계가 테이블 위로 떨어진다. 과거 서하가 현재 서하 쪽을 보는 듯 고개를 든다.

**과거 서하**
사람도 버리지 말 것.

현재 서하가 멈춘다.

**도윤**
들었습니까?

**서하**
원본 대사인지 공명인지 모릅니다.

**도윤**
또 근거가 부족하네요.

**서하**
그래서 안 가져갑니다.

도윤이 시계를 한 번 본 뒤 출구로 돌아선다.

**도윤**
잘하셨습니다.

서하가 그 말에 서운한 얼굴을 하자 도윤이 덧붙인다.

**도윤**
물건 말고 사람 데리고 나가시니까.

둘이 빈손으로 출구를 넘는다.

## S#7. 잔시물 관리센터 분류실 / 내부 / 새벽

둘은 빈손으로 돌아온다. 그런데 도윤의 손목에는 시계 자국이 더 짙어져 있다.

**도윤**
뭘 안 가져왔는데도 남네요.

서하가 자기 빈 손목을 본다. 같은 너비의 하얀 자국.

**도윤**
선배님은 뭘 받았습니까?

**서하**
아직 확인 안 했어요.

**도윤**
확인할 곳이 있습니까?

서하가 사물함 쪽을 본다. 문틈에서 남성용 셔츠 소매가 흘러나와 있다.

그녀가 급히 문을 닫으려 하지만 도윤이 소매 끝을 먼저 본다.

**도윤**
제 사이즈 같은데요.

**서하**
센터 세탁물입니다.

**도윤**
선배님 사물함에서요?

**서하**
분류 오류입니다.

도윤이 웃지 않고 그녀 손목 자국을 본다.

**도윤**
물건도 몸도 자꾸 같은 오류를 내네요.

    [12초. 사물함 문이 완전히 닫히지 않고 셔츠의 두 번째 단추 자리만 보인다.]
